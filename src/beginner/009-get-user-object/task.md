# 9 — getUserObject

**Poziom:** Beginner

Napisz funkcję `getUserObject(firstName, lastName, age)`, która zwraca obiekt `{ fullName, age, isAdult }` gdzie `fullName = firstName + ' ' + lastName` i `isAdult = age >= 18`.

## Przykłady
- `getUserObject('Jan', 'Kowalski', 25)` → `{ fullName: 'Jan Kowalski', age: 25, isAdult: true }`
