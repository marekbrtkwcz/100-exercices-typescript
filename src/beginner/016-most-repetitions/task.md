# 16 — mostRepetitions

**Poziom:** Beginner

Napisz funkcję `mostRepetitions(arr: string[]): string`, która zwraca element występujący najczęściej. Przy remisie zwraca pierwszy napotkany.

## Przykłady
- `mostRepetitions(['a', 'b', 'a', 'c', 'b', 'a'])` → `'a'`
- `mostRepetitions(['x', 'y'])` → `'x'`
