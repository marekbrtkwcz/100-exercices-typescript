# 7 — lastNRevert

**Poziom:** Beginner

Napisz funkcję `lastNRevert(arr: T[], n: number): T[]`, która zwraca tablicę z ostatnich `n` elementów ułożonych w odwrotnej kolejności.

## Przykłady
- `lastNRevert([1, 2, 3, 4, 5], 3)` → `[5, 4, 3]`
- `lastNRevert(['a', 'b', 'c'], 2)` → `['c', 'b']`
- `lastNRevert([1, 2], 5)` → `[2, 1]` (n większe niż długość)
