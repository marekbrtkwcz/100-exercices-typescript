# 23 — halfAndHalf

**Poziom:** Beginner

Napisz funkcję `halfAndHalf(str: string): [string, string]`, która dzieli string na dwie połówki. Jeśli długość jest nieparzysta, pierwsza część dostaje jeden znak więcej.

## Przykłady
- `halfAndHalf('hello')` → `['hel', 'lo']`
- `halfAndHalf('abcd')` → `['ab', 'cd']`
