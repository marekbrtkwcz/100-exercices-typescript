# 12 — getBiggestNumberInArrays

**Poziom:** Beginner

Napisz funkcję `getBiggestNumberInArrays(arrays: number[][]): number`, która znajduje największą liczbę wśród wszystkich podtablic.

## Przykłady
- `getBiggestNumberInArrays([[1, 5], [3, 9], [2, 7]])` → `9`
- `getBiggestNumberInArrays([[-1, -5], [-3, -2]])` → `-1`
