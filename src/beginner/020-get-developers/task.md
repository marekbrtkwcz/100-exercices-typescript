# 20 — getDevelopers

**Poziom:** Beginner

Napisz funkcję `getDevelopers(users: { name: string; role: string }[]): string[]`, która zwraca tablicę nazw (`name`) osób z rolą `'developer'`.

## Przykłady
- `[{name:'Jan',role:'developer'},{name:'Anna',role:'designer'},{name:'Piotr',role:'developer'}]` → `['Jan', 'Piotr']`
