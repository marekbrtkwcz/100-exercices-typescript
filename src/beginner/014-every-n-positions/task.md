# 14 — everyNPositions

**Poziom:** Beginner

Napisz funkcję `everyNPositions<T>(arr: T[], n: number): T[]`, która zwraca co n-ty element tablicy (indeksy 0, n, 2n, ...).

## Przykłady
- `everyNPositions([1, 2, 3, 4, 5, 6], 2)` → `[1, 3, 5]`
- `everyNPositions(['a', 'b', 'c', 'd'], 3)` → `['a', 'd']`
