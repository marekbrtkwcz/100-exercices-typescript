# 21 — extractElementsBetweenPositions

**Poziom:** Beginner

Napisz funkcję `extractElementsBetweenPositions<T>(arr: T[], start: number, end: number): T[]`, która zwraca elementy tablicy od indeksu `start` do `end` (wyłącznie).

## Przykłady
- `extractElementsBetweenPositions([1,2,3,4,5], 1, 4)` → `[2, 3, 4]`
