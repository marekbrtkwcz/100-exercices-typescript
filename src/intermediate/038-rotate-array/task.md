# 38 — rotateArray

**Poziom:** Intermediate

Napisz funkcję `rotateArray<T>(arr: T[], n: number): T[]`, która przesuwa elementy tablicy o `n` pozycji w prawo (ostatnie lądują na początku). `n` może być ujemne (w lewo).

## Przykłady
- `rotateArray([1, 2, 3, 4], 1)` → `[4, 1, 2, 3]`
- `rotateArray([1, 2, 3, 4], -1)` → `[2, 3, 4, 1]`
