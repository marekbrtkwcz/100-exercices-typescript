# 49 — isValidPassword

**Poziom:** Intermediate

Napisz funkcję `isValidPassword(password: string): boolean`. Hasło jest ważne gdy: min. 8 znaków, zawiera wielką literę, małą literę, cyfrę i znak specjalny (!@#$%^&*).

## Przykłady
- `isValidPassword('Haslo123!')` → `true`
- `isValidPassword('slabe')` → `false`
