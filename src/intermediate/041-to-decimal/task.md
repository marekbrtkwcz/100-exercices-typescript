# 41 — toDecimal

**Poziom:** Intermediate

Napisz funkcję `toDecimal(num: number, places: number): number`, która zaokrągla liczbę do `places` miejsc po przecinku.

## Przykłady
- `toDecimal(3.14159, 2)` → `3.14`
- `toDecimal(1.005, 2)` → `1.01` (lub 1, zależnie od implementacji — użyj Math.round)
