# 67 — searchMessages

**Poziom:** Intermediate

Napisz funkcję `searchMessages(messages: { id: number; text: string }[], query: string): { id: number; text: string }[]`, która zwraca wiadomości zawierające `query` (case-insensitive).

## Przykłady
- query 'hello' łapie 'Hello world' i 'say hello!'
