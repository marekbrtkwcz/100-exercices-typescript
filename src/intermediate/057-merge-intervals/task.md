# 57 — mergeIntervals

**Poziom:** Intermediate

Napisz funkcję `mergeIntervals(intervals: [number, number][]): [number, number][]`, która scala nakładające się przedziały.

## Przykłady
- `mergeIntervals([[1,3],[2,6],[8,10],[15,18]])` → `[[1,6],[8,10],[15,18]]`
- `mergeIntervals([[1,4],[4,5]])` → `[[1,5]]`
