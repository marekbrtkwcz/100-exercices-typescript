# 54 — simpleCompression

**Poziom:** Intermediate

Napisz funkcję `simpleCompression(str: string): string`, która kompresuje string przez zamianę powtarzających się znaków na znak + liczbę, np. 'aaabbc' → 'a3b2c1'. Jeśli wynik nie jest krótszy, zwraca oryginał.

## Przykłady
- `simpleCompression('aaabbc')` → `'a3b2c1'`
- `simpleCompression('abc')` → `'abc'` (krótszy oryginał)
