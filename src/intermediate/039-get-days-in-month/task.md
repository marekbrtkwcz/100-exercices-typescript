# 39 — getDaysInMonth

**Poziom:** Intermediate

Napisz funkcję `getDaysInMonth(year: number, month: number): number`, która zwraca liczbę dni w danym miesiącu (month 1-12). Uwzględnij rok przestępny dla lutego.

## Przykłady
- `getDaysInMonth(2024, 2)` → `29` (przestępny)
- `getDaysInMonth(2023, 2)` → `28`
- `getDaysInMonth(2024, 4)` → `30`
